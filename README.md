# 外資報告週摘

每週一份跨券商的外資研究盤點。每份報告一篇 3,000–5,000 字的精華、
逐字引用的分析師原句、3–6 個關鍵字標籤，以及一張依報告內文數字重製的圖。

**這個 repo 只放衍生層。** 原始 PDF 與抽取出來的全文**不在這裡，也永遠不會進來** ——
原文逐頁蓋有可追溯到個人的浮水印，那條界線是結構性的（檔案住在版控之外），
不是靠 `.gitignore`。

## 這裡有什麼

| 路徑 | 內容 |
|---|---|
| `index.html` | 站台。標籤／券商／關鍵字檢索，點進去讀單篇 |
| `data/index.json` | 檢索層：週次、每份的券商標題標籤與一句話 |
| `data/<週日>.json` | 那一期的完整內容（精華、原句、圖表規格） |
| `charts/<週次>/` | 重製圖的 PNG 與 SVG |

## 產生方式

程式、門檻與撰寫規則都在 [`kb-core`](https://github.com/GunDamnBoy/kb-core)，
不在這裡 —— 資料 repo 只放**已發布的東西**，
把門檻放進來會讓「改門檻」跟「改資料」混在同一個歷史裡。

發布走 `kb-core/tools/publish.py`，系統 id 是 `broker-research-digest`
（與 `.kb-data-repo` 逐字相同）。已發布的一期不改寫；要更正就掛 errata。

## 內容是怎麼來的

- **精華與交叉觀察**由 Claude 依報告內文整理，不是券商原文。
- **分析師原句逐字引用**，發布前經機械比對回抽取文字，對不上就整輪擋下。
- **圖表依報告內文明確寫出的數字重製**，不是原圖翻拍；
  每個數字的出處都以原文片段列在圖下，同樣經機械比對。
